# Karolina Bengtsson — Soprano

Editorial catalogue site for the Swedish soprano. Single static page: paper stock, serif display, programme-index calendar, listening desk.

## Open locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Contents

| Path | Role |
| --- | --- |
| `index.html` | Semantic page: masthead, hero, calendar, biography, repertoire, archive, representation |
| `css/editorial.css` | Design tokens and editorial layout |
| `js/site.js` | Scroll state, calendar “today”, archive player |
| `assets/img/` | Press portraits (Holmberg, Sjöqvist) |

## Sources

Biography, awards, and season roles follow public materials from [Braathen Artist Management](https://www.braathenmanagement.com/eng/artists/karolina-bengtsson), [Oper Frankfurt](https://oper-frankfurt.de/en/ensemble/ensemble/?detail=1144), and the [Birgit Nilsson Stipendium](https://birgitnilsson.com/stipendium/en/karolina-bengtsson-awarded-this-years-birgit-nilsson-stipendium/). Calendar dates are taken from the 2026/27 Spielplan. Casting remains the theatre’s.
